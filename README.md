# 🔥 소방청 10개년 화재발생 상세정보 검색 & 통계 분석 포털

소방청 및 공공데이터포털(data.go.kr)의 화재발생 상세정보 Open API를 기반으로 최근 **10년간(2017년 ~ 2026년)** 의 화재 사건 데이터를 상세 검색하고, 다차원 조건으로 정렬하며, 시각화 통계 분석과 CSV 내보내기를 지원하는 대시보드 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **10개년(2017~2026) 화재 데이터 다차원 검색 & 필터**
   - **키워드 검색**: 장소, 지역, 발화 원인, 개요 등 실시간 통합 검색
   - **연도/기간 범위 설정**: 10개년 전체, 특정 연도, 최근 3년/5년 프리셋
   - **행정구역 필터**: 전국 17개 시·도 및 시·군·구 단위 상세 필터링
   - **발화 원인별 분류**: 부주의(담배꽁초, 음식물조리 등), 전기적 요인, 기계적 요인, 방화 등
   - **장소 구분별 분류**: 주거시설(아파트, 단독주택), 산업시설, 상업시설, 운송수단, 임야 등
   - **피해 규모 조건**: 사망자 발생 사건만 필터링 등

2. **고성능 다차원 정렬 (Sorting Engine)**
   - **발생일시순** (최신순 / 오래된순)
   - **총 인명피해(사상자)순** (사상자 많은순)
   - **사망자 많은순**
   - **부상자 많은순**
   - **재산피해액순** (높은순 / 낮은순)
   - **진압소요시간순**
   - 테이블 헤더 클릭을 통한 즉각적인 정렬 순서 토글

3. **통계 및 시각화 대시보드 (Chart.js)**
   - **실시간 KPI 카드**: 총 화재건수, 총 사상자수, 사망자수, 부상자수, 총 재산피해액
   - **10개년 연도별 발생 추이 복합 차트**: 연간 화재 발생 건수(막대) + 사상자 추이(꺾은선)
   - **발화원인별 점유율 도넛 차트**: 부주의, 전기, 기계 등의 비율
   - **시·도별 화재 건수 랭킹 바 차트**
   - **장소별 분류 파이 차트**

4. **사건 상세정보 모달 & 데이터 내보내기**
   - 사건별 출동 소방관 수, 동원 소방차량 수, 소요시간, 세부 개요 조회
   - 현재 검색 및 정렬된 전체 결과를 Excel 호환 UTF-8 BOM CSV 파일로 즉시 다운로드

5. **2가지 동작 모드 지원**
   - **10개년 통합 데이터셋 모드 (기본)**: API 인증키 발급 전이어도 수천 건의 현실적인 10개년 화재 데이터를 즉시 탐색/정렬/분석 가능
   - **공공데이터포털 실시간 API 모드**: 공공데이터포털에서 발급받은 일반 인증키를 상단 설정에서 입력하여 실시간 연동 가능

## 🚀 빠른 시작 (실행 방법)

### 방법 1. 윈도우 원클릭 실행
폴더 내의 **`run.bat`** 파일을 더블 클릭하여 실행합니다.

### 방법 2. 명령 프롬프트(터미널)에서 실행
```bash
# 1. 의존성 패키지 설치
python -m pip install -r requirements.txt

# 2. 서버 실행
python run.py
```

실행 후 웹 브라우저에서 `http://127.0.0.1:8000` 으로 접속됩니다.

## 🛠 기술 스택

- **Backend**: Python 3.10+, FastAPI, Uvicorn, HTTPX, Pydantic
- **Frontend**: HTML5, Tailwind CSS, JavaScript (ES6+), Chart.js, FontAwesome, Pretendard
- **Data**: 공공데이터포털(data.go.kr) 소방청 화재발생정보 API 연동 및 10개년 통계 시드 엔진
